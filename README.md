## 🎯 项目简介

基于深度学习的胸部X光图像分析项目，可用于：

- 🔍 肺部疾病检测
- 📊 X光图像分类
- 🎯 病变区域定位

---

## 🚀 快速开始

```bash
git clone https://github.com/520llw/chest-xray.git
cd chest-xray
pip install -r requirements.txt
python main.py
```
